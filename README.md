# Data Science Internship Portfolio

This repository is the central index for my completed and developing data science projects. It only presents work that can be inspected in my public GitHub repositories; planned projects are not presented as completed work.

## Current projects

### [Heart Disease Prediction](https://github.com/Danniejnr/heart-diseases-prediction)

An end-to-end binary classification project using clinical data. The work covers data preparation, exploratory analysis, Logistic Regression, Decision Trees, Random Forest, cross-validation, threshold tuning, ROC-AUC evaluation, and model interpretation.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn

### [Metabolic Flux Optimization](https://github.com/Danniejnr/Metabolic-Flux-Optimization)

A computational biology project exploring flux balance analysis with an *E. coli* metabolic model. It connects my biochemistry background with Python-based biological modelling.

**Tools:** Python, COBRApy, Pandas, NumPy

### [Genomic Data Visualization](https://github.com/Danniejnr/Genomic-Data-Visualization)

An exploratory project for visualising synthetic gene-expression data. It demonstrates data organisation and heatmap creation while serving as a foundation for future work with real transcriptomic datasets.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

### [Scholarship Opportunity Web Scraper](https://github.com/Danniejnr/Scholarship-Opportunity-Web-Scraper)

A Python automation project designed to collect public scholarship listings and structure the extracted information for filtering and analysis.

**Tools:** Python, Requests, Beautiful Soup, Pandas

### [Learning Journey](https://github.com/Danniejnr/My-learning-Journey)

A structured archive of exercises and developing work across Python, SQL, statistics, data analysis, machine learning, and bioinformatics. This repository documents progression; the standalone repositories above contain the stronger portfolio pieces.

## Portfolio standard

Each featured project is being developed toward the same standard:

1. A clearly defined problem
2. Traceable data sources
3. Reproducible setup instructions
4. Documented methodology
5. Verified results and limitations
6. Clean code and understandable outputs
